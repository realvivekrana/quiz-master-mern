# 🧠 Quiz Master MERN

A full-stack **Quiz Management and Online Quiz Application** built using the **MERN Stack**.

Quiz Master allows users to create an account, play quizzes, track their performance, view previous attempts, and compete through leaderboards. It also includes a dedicated **Admin Panel** for managing quizzes and users.

## 🔐 Authentication

The application uses **JSON Web Tokens (JWT)** for authentication.

After a successful login, a JWT token is generated by the backend and used by the frontend to access protected API endpoints.

The application supports two roles:

```text
user
admin
```

### User

Users can play quizzes, view results, check leaderboards, and track their quiz history.

### Admin

Admins can access the Admin Panel and manage quizzes and registered users.

---

## 🎯 Quiz System

Each quiz can contain:

- Title
- Description
- Category
- Difficulty
- Duration
- Multiple Questions
- Multiple Options
- One Correct Answer per Question

After submitting a quiz, the backend calculates:

- Score
- Correct Answers
- Incorrect Answers
- Total Questions
- Time Taken

The result is stored in MongoDB for quiz history and leaderboard functionality.

---

## 🏆 Leaderboard

Each quiz includes a leaderboard where players can compare their performance.

Leaderboard ranking is based on quiz results, with score as the primary ranking factor.

## 🌐 API Endpoints

### Authentication

```http
POST /api/auth/register
POST /api/auth/login
```

### Quizzes

```http
GET    /api/quizzes
GET    /api/quizzes/:id
POST   /api/quizzes
PUT    /api/quizzes/:id
DELETE /api/quizzes/:id
POST   /api/quizzes/:id/submit
GET    /api/quizzes/:id/leaderboard
```

### Results

```http
GET /api/results/me
```

### Admin

```http
GET   /api/admin/users
PATCH /api/admin/users/:id/role
```

```bash
git clone YOUR_REPOSITORY_URL
```

```bash
cd quiz-master-mern
```

---

## 🖥️ Backend Setup

Move to the backend directory:

```bash
cd Backend
```

Install dependencies:

```bash
npm install
```

Create a `.env` file inside the `Backend` directory:

```env
PORT=5000
MONGO_URI=YOUR_MONGODB_CONNECTION_STRING
JWT_SECRET=YOUR_SECRET_KEY
```

Start the backend:

```bash
npm run dev
```

The API will run at:

```text
http://localhost:5000
```

---

## 💻 Frontend Setup

Open another terminal and move to the frontend directory:

```bash
cd Frontend
```

Install dependencies:

```bash
npm install
```

Start the frontend:

```bash
npm run dev
```

Vite will display the local development URL in the terminal.

---

## 🔑 Environment Variables

The backend requires environment variables such as:

```env
PORT=5000
MONGO_URI=YOUR_MONGODB_CONNECTION_STRING
JWT_SECRET=YOUR_SECRET_KEY
```

> Never commit the `.env` file to GitHub.

Add environment files to `.gitignore`:

```gitignore
.env
.env.*
```
